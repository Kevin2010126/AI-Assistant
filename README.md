# 수행평가 작업실

수행평가 일정을 등록하고, AI가 아웃라인/준비 일정/유형별 피드백을 만들어주고,
그 기록을 기기에 저장해서 언제든 다시 볼 수 있는 순수 HTML/CSS/JS 웹앱입니다.
서버 없이 GitHub Pages 등 정적 호스팅에 그대로 올릴 수 있어요.

## 기능
1. **일정 등록 + D-2 알림** — 과목/제목/유형/마감일을 입력하면 목록에 D-day와 함께 표시됩니다.
   브라우저 알림 권한을 켜두면, 마감 2일 전에 알림이 뜹니다.
2. **AI 준비 도우미** — 안내 내용을 입력하거나 PDF/TXT 유인물을 올리면, Gemini API가
   - 글쓰기 → 서론/본론/결론 아웃라인
   - 발표 → 도입/본론/결론 발표 구조 + 슬라이드 개요
   - 실험 → 가설/준비물/절차/보고서 목차

   를 유형에 맞게 만들고, 마감일까지 단계별 준비 일정(체크리스트)과 유형별 감점 방지 피드백을 함께 줍니다.
3. **기록 저장** — 실행한 모든 AI 분석 결과는 이 기기의 localStorage에 저장되어, "지난 기록" 탭에서
   언제든 다시 열어볼 수 있습니다.
4. **유형별 피드백** — 같은 프롬프트를 쓰지 않고, 글쓰기/발표/실험/기타 유형별로 지시문을 다르게 구성해
   서로 다른 결과를 만들어냅니다 (`js/ai.js`의 `TYPE_INSTRUCTIONS` 참고).

## GitHub Pages로 배포하기
1. 이 폴더 전체를 새 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 배포 브랜치를 지정합니다 (예: `main`, 루트 폴더).
3. 몇 분 후 `https://아이디.github.io/저장소이름/`에서 접속할 수 있습니다.
4. 아이폰/아이패드에서는 Safari로 접속 후 "공유 → 홈 화면에 추가"를 하면
   앱처럼 아이콘이 생깁니다 (스크린샷의 "아이패드 홈 추가"와 동일한 효과) 
## 알림에 대한 중요한 한계
브라우저의 `Notification` API와 서비스 워커만으로는, **브라우저/탭을 완전히 종료한 상태에서도
울리는 진짜 푸시 알림**은 만들 수 없습니다 (이건 서버가 있어야 가능해요, 예: Firebase Cloud
Messaging + 백엔드). 이 앱은:
- 앱을 열어둔 동안 30분마다 D-2 여부를 확인해서 알림을 띄우고,
- 서비스 워커가 살아있는 동안에도(브라우저가 완전히 꺼지지 않은 경우) 동작할 수 있습니다.

마감을 절대 놓치지 않으려면, 등록할 때 아이폰/구글 캘린더나 미리 알림에도 동일한 D-2 일정을
같이 추가해두는 것을 추천해요. 원한다면 이후에 백엔드(예: Cloudflare Workers + Web Push)를
붙여서 진짜 백그라운드 푸시로 확장할 수 있도록 코드가 모듈화되어 있습니다
(`js/notifications.js`만 교체하면 됩니다).
